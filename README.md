## Playwright TodoMVC Test Suite
This repository contains my first automated end to end testing projects using PlayWright and JavaScript

This project demostrates essential QA fundemental concepts which include

- Page Navigation
- Element interaction
- Assertion
- Test Execution

## Application to be Tested

Todo MVC React Application

https://todomvc.com/examples/react/dist/

## Test Coverage

Here is what the test suite currently tests  (As of June 6, 2026)
- Loading the TodoMVC application
- Creating a new todo item
- Verifying that the todo item is displayed correctly
- Basic user interaction with the application

## Running the Tests

Ensure that you have npm and playwright is intalled in your environment

Here is the line to execute the tests

npx playwright test
